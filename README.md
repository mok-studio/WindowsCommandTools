# WindowsCommandTools

**此项目由DeepSeek Harness制作，感谢AI Agent提供的便利！**

> **用可视化面板替代记忆命令语法。**
> 把 CMD 和 PowerShell 变简单：输入命令自动提示下一个参数，参数可以填表，危险操作会拦一下。

[**English**](README.en.md) · **简体中文**

---

## 这是什么

一个 Windows 桌面工具，解决三件日常麻烦事：

1. **记不住参数** —— 输入 `ping ` 就告诉你接下来能填什么，不用去查文档
2. **记不住命令** —— 445 条常用 CMD / PowerShell 命令内置，按分类翻，点一下就填进命令行
3. **分不清该用哪个** —— 在 PowerShell 里敲 `ping` 会提示你「这是 CMD 命令」，点一下就能切过去

单文件 exe，**不需要安装任何运行时**（.NET Framework 4.8 是 Windows 自带的）。

---

## 特性

| | |
|---|---|
| **双引擎** | CMD 与 PowerShell 一键切换；互不认识对方的命令时会提示并支持一键切过去 |
| **智能参数提示** | 输入命令 + 空格 → 按语法顺序列出可用参数、枚举值、文件路径，Tab 补全 |
| **可视化参数表单** | 选中命令自动生成表单，填完直接执行，不用拼参数 |
| **多命令执行** | 输入框切成多行文本区，一整段脚本一次跑完 |
| **多进程执行** | 独立窗口里 N 条任务各起一个进程，输出分开、可单独停止、标签页切换 |
| **定时 / 循环** | 排到某个时间点执行，或按间隔反复执行 |
| **主题与外观** | 8 套预设 + 自定义配色 + 毛玻璃 + 可调圆角，支持为 CMD / PowerShell 各配一套 |
| **中英双语** | 界面语言可切换；命令库说明保持中文 |
| **便携模式** | exe 旁边放一个 `WCTdata` 文件夹即变便携；不改设置就不写任何文件 |

## 快速开始

### 直接使用

1. 下载 `WindowsCommandTools.exe`
2. 双击运行，**不需要安装**

### 便携模式

想让配置跟着 exe 走，在**同一目录**建一个名为 `WCTdata` 的文件夹即可：

```
WindowsCommandTools.exe
WCTdata\            ← 建这个文件夹 = 便携模式
```

没有这个文件夹时，配置存到 `%APPDATA%\WindowsCommandTools`。

> **什么都不改就什么都不写。** 只有你把某项设置改成与默认不同时，程序才会创建 `WCTdata` 并落盘；改回默认后多余的文件会被自动删除。

## 界面

主窗口分三栏：

```
┌───────────┬─────────────────────────────┬──────────────┐
│ 命令库     │  命令行输入                  │  参数提示     │
│ 分类筛选   │  ────────────────────────   │  参数表单     │
│ 搜索框     │  定时/循环 …  多命令  多进程  │  命令详情     │
│ 命令卡片   │  ────────────────────────   │              │
│           │  输出控制台（可滚动）         │              │
│           │  底部固定帮助条               │              │
└───────────┴─────────────────────────────┴──────────────┘
```

- **左栏**：`常用 / 收藏 / 历史` + 各分类，点一下筛选；搜索框跨分类搜索
- **中栏**：输入框 + 运行时工具条 + 输出控制台
- **右栏**：三个页签 —— 参数提示、可视化表单、命令详情

### 参数提示怎么用

```
输入  ipconfig          → 提示「ipconfig 属于 CMD」（如果你是 PowerShell 模式）
输入  ping              → 第一个候选是「(切换到 CMD) ping」，点它就切过去
输入  ping 1.1.1.1 -    → 只列出 - 开头的开关
输入  ping -n           → 提示这里要填「次数」
输入  netsh wlan show   → 提示后面可以接 profiles / interfaces / …
```

规则很简单：**提示顺序 = 命令库里参数的书写顺序**。你按什么顺序写，就按什么顺序提示，引擎不做二次排序。

### 多进程执行

点提示行右侧的「多进程」打开独立窗口：

- 左命令库 / 中任务行 / 右参数提示，与主窗口同源
- 标题栏 `+` / `−` 增减任务行数（上限可在设置里调，默认 8）
- 每行可单独指定用 CMD 还是 PowerShell 执行；点了「(切换到 CMD) xxx」候选会自动把**那一行**切过去，窗口模式不变
- 输出的标签页可以**左右拖动排序**，也可以**右键弹出为独立窗口**

### 定时 / 循环

输入框下面那行的左侧就是：

```
🕐 [定时] [+30s] [循环] [5s] [停止]           [多命令] [多进程]
```

- **定时**：`HH:mm` / `HH:mm:ss`，或 `+30s`、`+5m` 这样的相对时间
- **循环**：`5s` / `1m` / `2h`；上一轮没跑完就跳过这一轮，不排队堆积

## 快捷键

| 按键 | 作用 |
|---|---|
| `Tab` | 补全当前候选 |
| `↑` `↓` | 选择候选 |
| `Enter` | 执行 |
| `Ctrl+Enter` | 多命令模式下执行整段 |

```
cmd> ipconfig        用 CMD 跑这一条
ps> Get-Process      用 PowerShell 跑这一条
```

## 从源码构建

只需要系统自带的 .NET Framework 编译器，**不需要 Visual Studio、不需要联网**。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

构建脚本会：

1. 校验 `commands\cmd\*.json` 与 `commands\ps\*.json` 的命令库
2. 用 `csc.exe`（`/langversion:5`）编译成单个 exe
3. 复制命令库到 `dist\commands\`
4. 跑内置自检（**158 项**，覆盖提示引擎、跨工具识别、真实进程执行、编码、持久化等）
5. 核对 exe 的文件属性

产物在 `dist\WindowsCommandTools.exe`。

修改翻译或图标后：

```powershell
python tools\build_lang.py      # 重新生成 src\LangTable.cs
python tools\make_res.py        # 重新生成 build\app.res
```

## 常见问题

**Q：需要装 .NET 吗？**
不需要。Windows 10 / 11 自带 .NET Framework 4.8。

**Q：命令库只有 445 条，能加自己的吗？**
能。在 `commands\cmd\` 和 `commands\ps\` 下放 JSON 文件即可，格式照抄现有文件，改完重启程序生效。

**Q：在 PowerShell 里跑 `ping` 提示「这是 CMD 命令」？**
这是刻意的。点提示条上的「切换并重新执行」，或点候选卡片里的「(切换到 CMD) ping」。

**Q：高危命令会拦我吗？**
默认只做**二次确认**，不会静默阻止。可以在设置里关掉确认。

**Q：为什么提示顺序和我预期的不一样？**
提示顺序严格等于命令库 JSON 里 `nodes` 的书写顺序，引擎不二次排序 —— 这样「你按什么顺序写，就按什么顺序提示」，可预期。想改顺序就改 JSON。

**Q：程序在磁盘上留了什么？**
默认什么都不留。只有你改了设置才会创建 `WCTdata`（便携模式）或 `%APPDATA%\WindowsCommandTools`（安装模式）。

## 已知限制

- 提权（UAC）流程依赖系统安全桌面，自动化无法覆盖，只做了参数拼接与持久化的单元测试
- 英文界面在极窄窗口下个别标题会被省略号截断（控件优先让位）
- 绕过正常关闭直接强杀进程时，本次设置改动不会落盘
